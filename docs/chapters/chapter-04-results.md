> **หมายเหตุสถานะเอกสาร:** ข้อมูลในหัวข้อ **4.2** เป็นผลที่ตรวจวัดได้จริงจากการทดลองเบื้องต้น (*Data Spike*, `n = 131` ประกาศ ณ วันที่ 18 พฤศจิกายน 2569 จาก `docs/data-spike-2026-11-18.md`) ส่วนหัวข้อ **4.3–4.7** เป็นโครงสร้างรายงานสำหรับเติมผลลัพธ์จริงเมื่อดำเนินการเก็บข้อมูล 5,000+ ประกาศ ตรวจมือ 200 ประกาศ ฝึกสอน ML และเก็บแบบสอบถามครบถ้วน (กำกับด้วย `[อัปเดตหลังเก็บข้อมูลจริง/รันทดสอบ]`)

## 4.1 ผลการพัฒนาระบบและสถาปัตยกรรมโครงงาน

ระบบ **Skill Demand Intelligence (E′)** ได้รับการพัฒนาตามสถาปัตยกรรมเวอร์ชัน `v4.2` ประกอบด้วย 4 ส่วนหลักที่ทำงานเชื่อมโยงกัน:

1. **ส่วนฐานข้อมูลและคลังข้อมูล (`supabase/migrations/`):**
   - จัดแยก 5 Schemas (`staging`, `dw`, `mart`, `ml`, `public`) พร้อมเปิดใช้ Extension `pg_trgm`
   - ชั้น `dw` ประกอบด้วย 10 Dimension Tables (`dim_date` ช่วงปี 2025–2027, `dim_location` ครบ 77 จังหวัด + หลายจังหวัด + ต่างประเทศ พร้อมธง `is_south14`, `dim_skill`, `skill_alias`, `dim_occupation`, `dim_company`, `dim_source`, `dim_education`, `dim_experience`, `dim_employment_type`) และ 3 Fact Tables ในรูปแบบ Galaxy Schema (`fact_job_posting`, `fact_posting_skill`, `fact_labor_monthly`)
   - ชั้น `mart` เปิดให้อ่านเฉพาะสถิติรวม (`n >= 5`) โดยแยก `mart.pipeline_status` และ `mart.dq_summary` ไว้สำหรับ Admin เท่านั้น และชั้น `public.app_*` เปิดใช้ Row Level Security (RLS) ครบทั้ง 6 ตาราง
2. **ส่วนจัดเก็บและประมวลผลข้อมูล (`pipeline/`):**
   - **Polite Scraper (`pipeline/scraper/`):** รองรับ Discovery รายจังหวัด/รายหมวด, วางแผนสุ่มแบบแบ่งชั้น (`quota.py`), ดึงข้อมูลทีละ 1 request เว้นระยะ ≥ 5 วินาทีพร้อมหยุดทันทีเมื่อเจอ HTTP 403/429/CAPTCHA (`fetch.py`), ตัดข้อมูลผู้ติดต่อ HR ทิ้งตั้งแต่ขั้น Parse (`parse.py`), และ Re-discovery รายสัปดาห์ (`rediscover.py`)
   - **ETL & Taxonomy (`pipeline/etl/`, `taxonomy/`):** ทำความสะอาดเงินเดือน 30+ รูปแบบ, ตัดคำภาษาไทยด้วย `PyThaiNLP newmm`, จับคู่ทักษะสองภาษา, คิวเสนอ alias ด้วยกฎ Trigram Similarity, ตรวจคุณภาพข้อมูล 8 ด้าน (`validate.py`), และโหลดเข้า DW/Mart แบบ Idempotent
3. **ส่วนแบบจำลอง ML และ API บริการโมเดล (`pipeline/ml/`, `services/ml-api/`):**
   - ระบบเทรนและเปรียบเทียบ 5 โมเดล (Ridge, Random Forest, XGBoost, LightGBM, CatBoost) + Baseline ด้วย `GroupKFold(5)` ตาม `company_key` และ Nested `GroupKFold(3)` โดยห้ามใช้คอลัมน์เพศ อายุ และชื่อบริษัท
   - บริการ FastAPI `services/ml-api` (`/health`, `/predict`, `/predict/batch` ตรวจ `X-ML-Key`) เสิร์ฟโมเดล Champion เพียงตัวเดียว คู่กับ Fallback `mart.salary_prediction`
4. **ส่วนเว็บแอปพลิเคชัน (`apps/web/`):**
   - พัฒนาด้วย Next.js App Router, Tailwind CSS v4, Liquid Glass UI (มีโหมดทึบสำรอง `data-glass="off"`), Apache ECharts พร้อมปุ่ม "ดูเป็นตาราง", `<ProvenanceBadge>`, ระบบ Auth/RLS + ปุ่มเดโม 4 Persona, และแชท Gemini ลอยที่ตอบจาก `pageContext` เท่านั้น

### 4.2.2 ผลการวิเคราะห์ความครบถ้วนของฟิลด์ เงินเดือน และทักษะ (ตัวอย่าง `n = 131`)
จากตัวอย่าง 131 ประกาศ (21 ประกาศแรก + 110 ประกาศสุ่มรายจังหวัด; วันที่ประกาศ 11–18 พ.ย. 2569) สามารถแยกวิเคราะห์ JSON-LD `JobPosting` ได้สำเร็จ **131/131 ประกาศ (100%)** โดยมีผลดังนี้

| ตัวชี้วัด (จาก `n = 131`) | ผลที่พบ | นัยสำคัญต่อการออกแบบ |
|---|---|---|
| **ความครบฟิลด์โครงสร้างหลัก** (`title`, `company`, `province`, `occupational_category`, `industry`, `employment_type`, `date_posted`) | **100%** | JSON-LD มีเสถียรภาพสูง เหมาะเป็นแหล่ง Extract หลัก |
| **ฟิลด์อำเภอ (`district`) / วันหมดอายุ (`valid_through`)** | **80% / 0%** | JobThai ไม่ระบุ `valid_through` จึงต้องใช้ Re-discovery รายสัปดาห์ติดตาม `last_seen` |
| **การระบุเงินเดือนเป็นตัวเลข** | **56%** (รายเดือน 72, รายวัน 1) | มัธยฐาน **18,750 บาท/เดือน** (`p10 = 15,000`, `p90 = 30,000`); ต้องแปลงหน่วยรายวันเป็นรายเดือนและรายงาน Selection Bias |
| **วุฒิการศึกษา / ประสบการณ์ (โครงสร้าง vs Regex)** | โครงสร้าง **0% / 0%**, Regex **85% / 25%** | ต้องสกัดวุฒิและประสบการณ์จากข้อความด้วย Regex และกำหนด `"ไม่ระบุ/ไม่จำเป็น"` เป็นหมวดหนึ่ง |
| **การระบุเพศ / อายุ ในข้อความประกาศ** | **27% / 58%** | พิสูจน์ความเสี่ยงอคติ จึงห้ามใช้เพศและอายุเป็น Feature ของโมเดล ML (D6) |
| **การดึงทักษะเบื้องต้น (~40 ทักษะเริ่มต้น)** | **99%** มีทักษะ ≥ 1 (มัธยฐาน 3, เฉลี่ย 3.4) | แนวทาง Dictionary + Alias สามารถดึงทักษะได้จริง โดยทักษะเด่นในตัวอย่าง ได้แก่ Sales (82), Communication (44), Customer Service (26), Negotiation (24), English (24), Microsoft Excel (19) |
