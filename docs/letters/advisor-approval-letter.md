# หนังสือขออนุมัติดำเนินโครงงานและการเก็บข้อมูลเพื่อการศึกษา (T0.3)

> **คำแนะนำสำหรับผู้จัดทำ:** กรุณากรอกข้อมูลในช่อง `[...]` ให้ครบถ้วนก่อนพิมพ์หรือส่งอีเมลให้ `[ชื่ออาจารย์ที่ปรึกษา]` ลงนามอนุมัติ และเก็บสำเนาไว้เป็นหลักฐานในภาคผนวกของเล่มโครงงาน

---

**บันทึกข้อความ**

**ส่วนราชการ/หน่วยงาน:** สาขาวิชาคอมพิวเตอร์ธุรกิจ `[คณะ / มหาวิทยาลัย]`  
**ที่:** `[ระบุเลขที่หนังสือ หรือ เว้นว่างตามแบบฟอร์มสาขา]`  
**วันที่:** `[วันที่ เดือน พ.ศ.]`  
**เรื่อง:** ขออนุมัติดำเนินโครงงานและขออนุญาตเก็บข้อมูลประกาศรับสมัครงานสาธารณะเพื่อการศึกษา  

**เรียน** `[ชื่ออาจารย์ที่ปรึกษา]` (อาจารย์ที่ปรึกษาโครงงาน)

ข้าพเจ้า `[ชื่อ-สกุล]` รหัสนักศึกษา `[รหัสนักศึกษา]` (พร้อมคณะผู้จัดทำ `[ระบุรายชื่อเพิ่มเติม หากทำเป็นกลุ่ม]`) นักศึกษาชั้นปีที่ `[ชั้นปี]` สาขาวิชา `[สาขาวิชา/มหาวิทยาลัย]` ภาคการศึกษา `[ภาคการศึกษา/ปีการศึกษา]` มีความประสงค์ขออนุมัติดำเนินโครงงานจบเรื่อง **"Skill Demand Intelligence: ระบบวิเคราะห์ความต้องการทักษะในตลาดแรงงานไทยจากประกาศงาน ด้วยคลังข้อมูลและการเรียนรู้ของเครื่อง"** *(หัวข้อ E′)* โดยมีวัตถุประสงค์เพื่อพัฒนาคลังข้อมูล ระบบจัดหมวดหมู่ทักษะ (Taxonomy) แบบจำลองการเรียนรู้ของเครื่องสำหรับประมาณการช่วงเงินเดือน และเว็บแดชบอร์ดสนับสนุนการตัดสินใจสำหรับนักศึกษาและสถานศึกษา

ในการพัฒนาระบบดังกล่าว จำเป็นต้องนำข้อมูลประกาศรับสมัครงานสาธารณะมาใช้ฝึกสอนและทดสอบระบบวิเคราะห์ทักษะ ข้าพเจ้าขอรับรองแนวทางปฏิบัติที่เคร่งครัดด้านลิขสิทธิ์ เงื่อนไขการใช้งาน (Terms of Service: ToS) และพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA) ดังต่อไปนี้

---

## 1. แหล่งข้อมูลที่ใช้และแหล่งข้อมูลต้องห้าม
1. **แหล่งข้อมูลหลัก:** เว็บไซต์ **JobThai** (`https://www.jobthai.com`) ซึ่งเป็นหน้าประกาศงานที่ `robots.txt` อนุญาตให้เข้าถึงได้ (`Allow: /`) และผู้จัดทำจะส่งอีเมลขออนุญาตอย่างเป็นทางการไปยังทีมงาน JobThai ควบคู่กัน
2. **แหล่งข้อมูลสำรอง (กรณีจำเป็น):** เว็บไซต์ **JobBKK** (`https://www.jobbkk.com`) สำหรับการเก็บข้อมูลเพื่อการศึกษาเท่านั้น หาก JobThai ไม่อนุญาตหรือข้อมูลไม่เพียงพอ
3. **แหล่งข้อมูลที่ห้ามแตะต้องโดยเด็ดขาด:** **JobTopGun** (เนื่องจาก ToS ข้อ 3.3 ห้ามการทำ screen scraping และ data mining), **JobsDB / SEEK** (เนื่องจาก `robots.txt` ระบุ `Disallow: */job/`) และ **Indeed** โดยจะเขียนโค้ดป้องกันไม่ให้ระบบดึงข้อมูลจากแหล่งต้องห้ามเหล่านี้ได้

---

## 2. มาตรการเก็บข้อมูลอย่างสุภาพ (Polite Scraping)
1. **ไม่สร้างภาระต่อเซิร์ฟเวอร์ต้นทาง:** ดึงข้อมูลทีละ **1 request (Concurrency = 1)** และหน่วงเวลาไม่น้อยกว่า **5 วินาทีต่อ 1 request** (รวมช่วงสุ่ม jitter) โดยจำกัดการสุ่มแบบแบ่งชั้น (Stratified Sampling) ให้ได้ประมาณ 5,000–10,000 ประกาศในหลายช่วงเวลา ไม่ดึงข้อมูลทั้งเว็บไซต์ในคราวเดียว
2. **เปิดเผยตัวตนอย่างโปร่งใส:** ระบุชื่อโครงงาน จุดประสงค์เพื่อการศึกษา และ `[อีเมลติดต่อ]` ของผู้จัดทำในส่วนหัว `User-Agent` ของทุก request และไม่เรียกใช้งาน API ภายในที่ไม่ได้เปิดเผยต่อสาธารณะ
3. **หยุดทันทีเมื่อถูกจำกัดการเข้าถึง:** หากเซิร์ฟเวอร์ตอบกลับด้วยสถานะ HTTP `403`, `429` หรือพบหน้าตรวจสอบอัตโนมัติ (CAPTCHA) ระบบจะ**หยุดการทำงานทั้งรอบทันที** บันทึกสถานะลงฐานข้อมูล (`staging.scrape_run`) และ**จะไม่ทำการหลบเลี่ยง เปลี่ยน IP หรือแก้ CAPTCHA โดยเด็ดขาด**

---

## 3. การปฏิบัติตาม PDPA และความเป็นธรรมของแบบจำลอง
1. **ตัดข้อมูลส่วนบุคคลของฝ่ายบุคคลตั้งแต่ต้นทาง:** ระบบจะลบฟิลด์และข้อความที่เกี่ยวข้องกับผู้ติดต่อ HR ทั้งหมด (ชื่อผู้ติดต่อ เบอร์โทรศัพท์ อีเมล LINE ID รวมถึงคีย์ `telephone`, `email`, `contactPoint`, `applicationContact`) ตั้งแต่ขั้นตอนการแยกโครงสร้าง (parse) **ก่อน** บันทึกลงฐานข้อมูล `staging`
2. **ป้องกันอคติในโมเดลการเรียนรู้ของเครื่อง:** แม้ประกาศรับสมัครงานบางส่วนจะระบุเพศหรืออายุ แต่ระบบจะ**ห้ามนำเพศ (`gender`), อายุ (`age`) และชื่อบริษัท (`company_name`) เข้าเป็นตัวแปร (feature) ในโมเดล ML โดยเด็ดขาด** พร้อมเขียนชุดทดสอบอัตโนมัติตรวจสอบความถูกต้องก่อนฝึกสอนโมเดล

---

## 4. การปฏิบัติตามเงื่อนไขการใช้งาน (ToS) ในการแสดงผลบนเว็บ
1. **ไม่เผยแพร่เนื้อหาประกาศซ้ำ:** เว็บแอปพลิเคชันและ API สาธารณะจะแสดงเฉพาะ **ข้อมูลสถิติเชิงรวม (Aggregate)** ที่ผ่านเกณฑ์จำนวนตัวอย่างขั้นต่ำ (`n >= 5`) เท่านั้น เพื่อป้องกันการระบุตัวตนและการทำซ้ำเนื้อหา
2. **ให้เครดิตและลิงก์กลับไปยังต้นฉบับ:** จะไม่มีหน้าเว็บหรือ API ที่ส่งข้อความรายละเอียดประกาศ (`description`/`qualifications`) ออกไปสู่สาธารณะ แต่จะแสดงเฉพาะชื่อตำแหน่งสั้นๆ คู่กับลิงก์ไปยังหน้าประกาศต้นฉบับบนเว็บไซต์ JobThai เท่านั้น
3. **ความปลอดภัยของข้อมูลดิบ:** ข้อมูล HTML ดิบจะถูกเก็บเฉพาะในเครื่องพัฒนาที่อยู่หลัง `.gitignore` ไม่นำขึ้น Git Repository สาธารณะ และใช้เพื่อการศึกษาในรายวิชาโครงงานเท่านั้น ไม่แสวงหาผลประโยชน์เชิงพาณิชย์

---

## 5. แนวทางปฏิบัติหากเจ้าของข้อมูลไม่ตอบกลับหรือปฏิเสธคำขอ
- **กรณี JobThai อนุญาต:** ดำเนินการสุ่มเก็บข้อมูลตามแผน Polite Scraping และบันทึกหลักฐานการอนุญาตไว้ในระบบ
- **กรณี JobThai ปฏิเสธ:** หยุดการเก็บข้อมูลจาก JobThai ทันที และดำเนินการกับข้อมูลเดิมหรือลบข้อมูลตามคำขอของ JobThai และคำวินิจฉัยของอาจารย์ที่ปรึกษา
- **กรณี JobThai ไม่ตอบกลับภายในสัปดาห์ที่ 3:** ขอความอนุเคราะห์อาจารย์ที่ปรึกษาพิจารณาอนุมัติเป็นลายลักษณ์อักษรด้านล่างนี้ว่าสามารถเก็บข้อมูลเฉพาะหน้าสาธารณะแบบสุภาพเพื่อการศึกษาได้หรือไม่
