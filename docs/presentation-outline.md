## ส่วนที่ 2: สคริปต์ Demo สด 5 นาที (4 Persona)

> **กฎทองระหว่าง Demo:** เปิดแท็บเบราว์เซอร์เตรียมไว้ล่วงหน้า 1 แท็บที่หน้า `/` และ **เปิดหน้า `/salary` ทิ้งไว้ล่วงหน้าหรือให้ระบบยิง Pre-warm** เพื่อปลุก Render Free `ml-api` ก่อนถึงนาทีที่ 2:15

### นาทีที่ 0:00 – 1:15 | Persona 0 & 1: Visitor & นักศึกษาสาย Data (`Market Explorer` → `Skill Gap`)
1. **[0:00–0:35] หน้า `/` และ `/market` (Visitor):**
   - ชี้ให้เห็น 4 KPI จาก `mart.public_summary` (ไม่เปิด `pipeline_status`), `<ProvenanceBadge>` ("ตัวอย่างจากประกาศ JobThai"), และกฎ **ไม่มีข้อความรายละเอียดประกาศ**
   - กดเข้า `/market` ปรับ Global Context Bar เลือกภาค/จังหวัด (เช่น `กรุงเทพมหานคร` vs `ทั้งประเทศ`) → ชี้ Ranked Bars, Sankey Skill Flow และปุ่ม **"ดูเป็นตาราง"**
   - กดที่แท่งทักษะ `SQL` เพื่อเปิด `/skills/sql` ดูแนวโน้มรายสัปดาห์และ Co-occurrence
2. **[0:35–1:15] ปุ่มเดโมคลิกเดียว: "นักศึกษาสาย Data" (`/login` → `/me/skills` → `/me/gap`):**
   - คลิกเข้าสู่ระบบใน 1 คลิก พาไปหน้า `/me/skills` (ลองพิมพ์ค้นหาคำไทย `"เอ็กเซล"` หรือ `"ไพธอน"` เพื่อโชว์ Alias Search)
   - สลับไป `/me/gap`: ชี้ Radar ฉัน vs ตลาด (ม่วง vs คอรัล), Coverage %, ทักษะที่ขาดอันดับต้นๆ และลิงก์ `"ดูประกาศต้นฉบับ ↗"` ที่ชี้กลับไปยัง JobThai

### นาทีที่ 1:15 – 2:30 | Persona 2: นักศึกษาสาย Accounting (`Salary Estimator` + `ML Lab` + `Gemini Chat`)
1. **[1:15–1:55] `/salary` (เปลี่ยนบริบทเป็นตำแหน่งสาย Accounting หรือ Data):**
   - เลือกตำแหน่ง กลุ่มจังหวัด ประสบการณ์ และทักษะ → กดคำนวณช่วงเงินเดือน
   - ชี้ **Champion Card** (แสดงช่วง `p25–p75`, ชื่อโมเดล Champion, คำเตือน *"ประมาณการจากประกาศที่ระบุเงินเดือน ไม่ใช่เงินเดือนจริง"* และไม่มีช่องกรอกเพศ/อายุ)
   - ชี้ Meter List *"ทักษะที่ถ้าเพิ่มแล้วค่าคาดเพิ่มขึ้น"* (ทำงานผ่าน `/predict/batch`)
2. **[1:55–2:15] เปิด `ChatPanel` มุมขวาล่าง:**
   - กดคำถามแนะนำ *"ทำไมช่วงเงินเดือนกว้างขนาดนี้"* หรือ *"เพิ่มทักษะไหนคุ้มสุด"* → แสดงให้เห็นว่า Gemini ตอบภาษาไทยโดยอ้างอิงเฉพาะตัวเลขบนการ์ดหน้า `/salary`
3. **[2:15–2:30] เปิด `/ml-lab`:**
   - ชี้ตารางเปรียบเทียบ 5 โมเดล + Baseline และอธิบายสั้นๆ ว่าเลือกใช้เฉพาะ Champion ตัวเดียวในระบบจริง

### นาทีที่ 2:30 – 3:45 | Persona 3: อาจารย์หลักสูตร (`Curriculum Alignment`)
1. **[2:30–3:45] คลิกเดโม "อาจารย์หลักสูตร" → `/institution/curricula`:**
   - เปิดหลักสูตรตัวอย่างที่ seed ไว้ ชี้ Gauge **Curriculum Coverage %**
   - ชี้ตาราง **Gaps** (ทักษะที่ตลาดขอสูงแต่หลักสูตรยังไม่มี) และ **Over-coverage** (ทักษะที่สอนแต่ตลาดขอน้อย) พร้อม Heatmap รายวิชา × ทักษะ
   - กดปุ่ม **Export CSV** เพื่อแสดงผลไฟล์สรุปที่นำไปประกอบการปรับปรุงหลักสูตรได้ทันที

### นาทีที่ 3:45 – 5:00 | Persona 4: Admin (`Pipeline / Data Quality / Taxonomy` & `Security`)
1. **[3:45–4:35] คลิกเดโม "Admin" → `/admin/pipeline` → `/admin/quality` → `/admin/taxonomy`:**
   - `/admin/pipeline`: ชี้ตารางรอบ scrape, สถานะความสุภาพ (`done` / `stopped_*`) และคำถามยอดนิยมจากแชท
   - `/admin/quality`: ชี้ผลตรวจ DQ 8 ด้าน (เน้น Compliance: 0 HR Contact, 0 Gender/Age ใน ML)
   - `/admin/taxonomy`: ชี้คิว Alias Pending ที่เสนอคู่ทักษะด้วยกฎ **`pg_trgm` (ไม่ใช้ AI)** แล้วทดลองกด Approve/Merge
2. **[4:35–5:00] ปิดท้ายเรื่องความปลอดภัยและ Accessibility:**
   - ชี้ Settings → สลับ **Glass Off Mode** (`data-glass="off"`) หรือย่อหน้าต่างเป็น **Mobile (375px)** เพื่อให้กรรมการเห็นความพร้อมด้าน Accessibility และ Responsive

## ส่วนที่ 3: แผนรับมือเหตุขัดข้องระหว่างสอบ (Fallback Handling Plan)

| สถานการณ์ฉุกเฉิน | อาการที่อาจเกิด | วิธีรับมือทันทีในห้องสอบ (ไม่เกิน 10 วินาที) |
|---|---|---|
| **1. Render Free `ml-api` หลับ / Timeout** | หน้า `/salary` รอผลเกิน 8 วินาที | ระบบออกแบบ Fallback อัตโนมัติไว้แล้ว: Proxy จะสลับไปดึงจาก **`mart.salary_prediction`** ทันที พร้อมแสดงป้าย *"ค่าประมาณที่คำนวณล่วงหน้า"* (สามารถอธิบายกรรมการให้เห็นความทนทานของระบบได้ทันที) |
| **2. Gemini API Quota หมด / ช้า** | แชทขึ้น error หรือตอบช้า | แสดงข้อความสุภาพ *"ตอบไม่ได้ในตอนนี้"* หรือใช้คำตอบเดโมสำรองที่เตรียมไว้สำหรับคำถามแนะนำ (`T7.5`) เพื่อให้ Flow สาธิตเดินต่อได้ |
| **3. อินเทอร์เน็ตห้องสอบหลุด / Supabase มีปัญหา** | โหลดหน้าเว็บออนไลน์ไม่ได้ | สลับไปใช้ **Local Environment** ที่รันไว้บนเครื่องนำเสนอ (`localhost:3000` + ข้อมูล Processed Local/Docker) และหากเครื่องขัดข้อง ให้เปิด **วิดีโอเดโมสำรองความละเอียดสูง (1080p)** ที่บันทึกซ้อมไว้ครบทั้ง 5 นาที |
| **4. กรรมการขอดูเบื้องหลังโค้ด/เทสต์** | ถามเรื่องกฎห้ามเพศ/อายุ หรือ RLS | เปิดหน้าต่าง Terminal/VS Code ที่เตรียมไว้ล่วงหน้า รันคำสั่ง `.\.venv\Scripts\python.exe -I -X utf8 -m pytest pipeline/tests -v` เพื่อพิสูจน์ผลเทสต์จริงทันที |
